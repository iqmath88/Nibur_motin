# Nibor Motion v0.12.0 — Interactive Geometry

يضيف تحرير رؤوس المثلث بالسحب وحساب الزوايا الداخلية فورياً، وإظهار قياس الزوايا على لوحة الفيديو، وخيار استعادة الشكل الافتراضي.

## الاستخدام
1. من استوديو الرياضيات > الأشكال الهندسية، أضف مثلثاً.
2. فعّل «تحريك الشكل باللمس» ثم «تحرير رؤوس المثلث باللمس».
3. اسحب أحد الرؤوس في معاينة الفيديو. قياسات الزوايا تظهر في لوحة الخيارات، ويمكن إظهارها على الفيديو عبر مربع الاختيار.
4. عطّل تحرير الرؤوس لتحريك الشكل كاملاً.

يظل حساب الزوايا معرفاً فقط للمثلث غير المنعدم المساحة. الأشكال القديمة تستورد بثلاثة رؤوس افتراضية، ونظام التحريك للدوائر والزوايا لا يتغير. جميع القياسات بوحدة الدرجة.

النشر: فك ضغط ZIP وارفع محتوياته إلى جذر مستودع iqmath88/Nibur_motin فقط.

ملاحظة: يلزم اختبار التفاعل وتصدير MP4 على الهاتف الفعلي.

## آلية القياسات
- قياسات الزوايا مشتقة من الإحداثيات المحلية للرؤوس الثلاثة؛ مجموعها 180° للمثلث غير المنعدم المساحة.
- المقابض البرتقالية لا تظهر في PNG أو الفيديو، بل أثناء تحرير الرؤوس في المعاينة فقط.
- لا تدعم هذه النسخة إنشاء قيود هندسية مثل تساوي الأضلاع أو التوازي؛ يجري حفظ الرؤوس الثلاثة بشكل مستقل.


## v0.12.1 — إصلاح المعادلات داخل نص السؤال

من محرر المشهد افتح «إدراج معادلة داخل نص السؤال»، ثم أدخل المعادلة باستخدام MathLive أو LaTeX، واضغط «إدراج المعادلة في السؤال». يدعم النص العربي مع معادلات متعددة في الجملة الواحدة باستخدام المحددات `\( ... \)` أو `$...$`. يُستخدم Canvas نفسه للمعاينة والتصدير.
