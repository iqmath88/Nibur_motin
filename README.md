# Nibor Motion v0.11.0 — استوديو الرياضيات

ترقية كاملة من v0.10.1، بلا مكتبات خارجية إضافية وبلا أدوات بناء.

## المزايا
- رسم دالة رياضية آمن (محلل تعبيرات دون eval) على Canvas مع محاور وشبكة.
- نقطة تتحرك وفق زمن المشهد، ومماس اختياري محسوب بفروق عددية مركزية.
- خطوات LaTeX تظهر بالتتابع مع مؤقت بداية وفاصل؛ رسمها يستخدم كاش MathJax الحالي.
- قلم تأشير حر باللمس أو S Pen، مع تراجع عن آخر خط ومسح الخطوط.
- حفظ الأدوات الجديدة في المشروع وJSON، والتوافق مع مشروعات الإصدارات القديمة.
- المعاينة وPNG وتصدير الفيديو تستخدم render() نفسه.

## الاستخدام
افتح **استوديو الرياضيات — الرسوم والقلم وخطوات الحل** في لوحة محرر المشهد. اكتب دالة مثل `x^2-4` أو `sin(x)` وفعل عرض الرسم. لتدوين خطوات الحل ضع LaTeX في كل سطر. لتفعيل الرسم اليدوي اضغط تفعيل القلم ثم ارسم داخل المعاينة؛ أوقف القلم قبل تحريك العناصر.

## حدود معروفة
- التعبيرات تحتاج معاملات صريحة (`2*x` وليس `2x`) والدوال المثلثية بالراديان.
- الخطوط المرسومة ثابتة زمنياً طوال المشهد، ولا يوجد تحرير نقاط الخط أو محرك هندسة متجهة.
- المماس عددياً تقريب فقط وليس برهاناً رياضياً؛ غير مناسب لنقاط عدم الاشتقاق.
- الخطوات تُعرض في منطقة أسفل الرسم ويمكن أن تتداخل مع عناصر موجودة؛ راجع المعاينة.
- لم يتم اختبار التصدير على Galaxy S25 Ultra فعلياً؛ التصدير يعتمد إمكانات المتصفح.


## v0.11.1 — هندسة وتحسين التحكم باللمس
- أدوات دائرة ومثلث وزاوية مرسومة متجهياً على Canvas وبنفس مسار التصدير.
- لكل شكل لون، حجم، دوران، تسمية، بداية ونهاية ظهور.
- تحريك العنصر المحدد في المعاينة بلمس أو قلم S Pen بعد تفعيل وضع تحريك الشكل.
- تخزين حتى 30 شكلاً لكل مشهد في بيانات المشروع مع قبول الملفات السابقة.
- التوقيت نسبي إلى المشهد؛ لا توجد بعد قيود هندسية ذكية أو قياسات زوايا محسوبة.
