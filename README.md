# Nibor Motion v0.6.0 — محرر النصوص والملصقات

تحديث محافظ على المشروع الحالي، يعمل دون أدوات بناء. ارفع ملفات الحزمة إلى جذر مستودع GitHub Pages مباشرة.

## الجديد
- حذف مباشر للملصق المحدد من أسفل المعاينة، أو من قائمة الملصقات. يتطلب تأكيد الحذف.
- التحكم بحجم عنوان المشهد ونص السؤال، وحجم المعادلة والنتيجة، ومواضعها العمودية.
- ستة أشكال لخلفيات العنوان والسؤال والنتيجة: بلا خلفية، مستطيل دائري، مستطيل، إطار، خط سفلي، تظليل.
- سبعة ألوان جاهزة للخلفيات مع الحفاظ على وضوح المعادلات في القوالب الداكنة.
- كل الإعدادات جزء من المشهد، تُحفظ في JSON؛ ملفات v0.5.0–v0.5.4 القديمة تستعيد القيم الافتراضية عبر cleanScene.
- المعاينة والتصدير يستدعيان render() نفسها على Canvas ذاته.

## تنبيهات
- لا يزال التصدير بصوت ودقة فعلية يعتمد على Safari/MediaRecorder. افحص الملف الناتج على الجهاز.
- لا تتضمن نسخة JSON ملفات الصوت؛ التسجيلات مخزّنة محلياً في IndexedDB.
- يجب تحميل MathJax وMathLive من CDN لاستخدام محرر المعادلات.
- لا تقم بحذف بيانات الموقع إذا كانت مشاريعك مخزّنة محلياً فقط.

## اختبار iPad
1. اختر الملصق باللمس ثم احذفه من الزر تحت المعاينة.
2. غيّر حجم العنوان والسؤال، واختر خلفية مختلفة؛ تحقق من عدم فقدان النص.
3. جرّب قوالب السبورة والداكن وبالذات خلفية النتيجة الكحلية والفاتحة.
4. احفظ المشروع، ثم استورد ملف JSON من v0.5.3 وقارن المظهر.
5. صدّر PNG ثم فيديو وتحقق من التطابق والصوت والدقة الحقيقية.
